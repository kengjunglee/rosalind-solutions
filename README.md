# rosalind-solutions

My solutions to bioinformatics problems from [Rosalind](https://rosalind.info/problems/list-view/), implemented in Python.

> Rosalind is a platform for learning bioinformatics through problem solving.

## Problems Solved

| File | Problem ID | Title |
|------|------------|-------|
| `dna.py` | [DNA](https://rosalind.info/problems/dna/) | Counting DNA Nucleotides |
| `rna.py` | [RNA](https://rosalind.info/problems/rna/) | Transcribing DNA into RNA |
| `revc.py` | [REVC](https://rosalind.info/problems/revc/) | Complementing a Strand of DNA |
| `fib.py` | [FIB](https://rosalind.info/problems/fib/) | Rabbits and Recurrence Relations |
| `gc.py` | [GC](https://rosalind.info/problems/gc/) | Computing GC Content |
| `hamm.py` | [HAMM](https://rosalind.info/problems/hamm/) | Counting Point Mutations |
| `prot.py` | [PROT](https://rosalind.info/problems/prot/) | Translating RNA into Protein |
| `subs.py` | [SUBS](https://rosalind.info/problems/subs/) | Finding a Motif in DNA |
| `fibd.py` | [FIBD](https://rosalind.info/problems/fibd/) | Mortal Fibonacci Rabbits |
| `perm.py` | [PERM](https://rosalind.info/problems/perm/) | Enumerating Gene Orders |
| `lexf.py` | [LEXF](https://rosalind.info/problems/lexf/) | Enumerating k-mers Lexicographically |
| `lexv.py` | [LEXV](https://rosalind.info/problems/lexv/) | Ordering Strings of Varying Length Lexicographically |
| `sign.py` | [SIGN](https://rosalind.info/problems/sign/) | Enumerating Oriented Gene Orderings |

## Requirements

- Python 3.x

## Usage

Each script reads input from a dataset file. Run any solution with:

```bash
python <filename>.py
```

## Notes

- `custom_io.py` is a shared utility module used across solutions for parsing input and writing results.
